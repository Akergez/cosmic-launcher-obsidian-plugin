# Obsidian для COSMIC launcher

Плагин pop-launcher: ищет заметки Obsidian и открывает их.

## Установка

```sh
./install.sh
pkill -x pop-launcher   # лаунчер перезапустит его сам
```

Плагин ставится симлинком в `~/.local/share/pop-launcher/plugins/obsidian`.

## Использование

- `<запрос>`: заметки ищутся по названию прямо в общей выдаче (до 5 результатов, от 2 символов).
- `ob <запрос>`: полный режим. Поиск по названию, пути и содержимому, до 20 результатов.
- `ob ` без запроса показывает последние изменённые заметки.
- В конце выдачи `ob <запрос>` есть пункт «Создать заметку», если заметки с таким названием нет.
- **Enter** открывает заметку. Под niri фокус переходит на окно Obsidian.
- **Tab** подставляет название заметки в строку поиска.

Хранилища берутся из `obsidian.json` (Flatpak, нативная установка, snap).
Каталоги `.obsidian`, `.trash` и скрытые пропускаются.

## Настройка

Константы в начале `obsidian-search`: префикс, число результатов, интервал пересканирования.
При смене префикса поменяй и `help` в `plugin.ron`.

Лог: `/tmp/obsidian-search-plugin.log`.
